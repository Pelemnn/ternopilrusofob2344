# 🇺🇦 Telegram-бот «Анти-Русифікатор»

Потужний і розумний Telegram-бот на Python (aiogram 3.x), створений для очищення українських чатів від російської мови, окупаційних слів, матів та одруківок із прогресивною системою покарань (мут-драбина), заміною на колоритну українську лайку, розширеними правами Супер-Адміна, налаштуванням таймінгів та колекцією з 30 пісень УПА!

---

## 👑 Супер-Адміністратор
Головний адміністратор бота: `998913975`. Має повний доступ до всіх команд у будь-якому чаті, може призначати інших адмінів та керувати налаштуваннями.

## 🚀 Основний функціонал

1. **Розумна детекція мови та одруківок:**
   - **Унікальні літери:** Миттєве виявлення літер `ы`, `ё`, `ъ`, `э`.
   - **Словник та патерни:** Суто російські слова (*«полотенце»*, *«привет»*, *«спасибо»*, *«пожалуйста»*, *«почему»*, *«конечно»*, *«сейчас»*, *«вообще»*, *«нравится»*).
   - **Ловля одруківок (Fuzzy Matching):** Розпізнає слова з помилками на клавіатурі (*«блч»* замість *«бля»*, *«првет»*, *«полотнце»*, *«пздц»*).
   - **Обхід фільтрів (Leetspeak):** Захист від маскування (*«бл@ть»*, *«$ука»*, *«п0шел»*).
   - **Захист від хибних спрацьовувань:** Українські слова не блокуються.

2. **Заміна російських матів на соковиту українську лайку:**
   - *«блять» / «бля»* 💡 *«Трясця! / Хай йому грець! / Дідько!»*
   - *«пошел нахуй»* 💡 *«Йди до сраки! / Під три чорти!»*
   - *«сука»* 💡 *«Курва! / Стерво! / Падлюка!»*
   - *«пиздец»* 💡 *«Срака! / Халепа! / Лихо!»*
   - *«ебать»* 💡 *«Йосип драний! / А щоб тебе підняло та гепнуло!»*
   - *«хуйня»* 💡 *«Дурня! / Хрінь! / Срамота!»*
   - *«еблан» / «долбоеб»* 💡 *«Бовдур! / Йолоп! / Недотепа!»*

3. **Прогресивна драбина покарань:**
   - За замовчуванням: **5хв ➔ 15хв ➔ 30хв ➔ 1год ➔ 12год ➔ 24год ➔ 36год**.
   - **Повна кастомізація через команду `/settings`:** адмін може встановити будь-який час на будь-який крок (наприклад, `/settings 1 36h`).

4. **🎵 Музичний плеєр УПА (`/music`):**
   - Відправляє одну з **30 культових українських повстанських та патріотичних пісень** із цитатою приспіву та посиланням на YouTube/трек.
   - Кулдаун: **1 хвилина**.

## 📋 Список команд

### Для користувачів:
- `/start` — Привітання та інформація.
- `/help` — Довідка з командами.
- `/music` — Випадкова повстанська пісня УПА (кулдаун 1 хв).
- `/my_punishments` — Моя кількість порушень.
- `/top` — Топ порушників чату.

### Для адміністраторів (Супер-адмін `998913975` + призначені через `/setfob`):
- `<code>/mute [причина] [термін]</code>` (відповіддю) — Мут на заданий час (наприклад: `/mute спам 10m` або `/mute 2h` або `/mute 36h`).
- `<code>/unmute</code>` (відповіддю) — Зняти мут.
- `<code>/setfob</code>` (відповіддю або `/setfob user_id`) — Призначити користувача адміном бота.
- `<code>/settings</code>` — Переглянути поточну драбину покарань.
- `<code>/settings [крок 1-7] [термін]</code>` — Змінити час муту (наприклад: `/settings 1 36h`).
- `<code>/reset</code>` (відповіддю) — Скинути лічильник покарань до 0.

## 🌐 Розгортання на Render.com

1. Створіть репозиторій на GitHub та запушіть код.
2. На [Render.com](https://dashboard.render.com/) створіть **Web Service**.
3. **Build Command:** `pip install -r requirements.txt`
4. **Start Command:** `python bot.py`
5. В **Environment Variables** додайте:
   - `BOT_TOKEN` = `ваш_токен`
6. Додайте URL на [UptimeRobot](https://uptimerobot.com/) на ендпоінт `/health` (кожні 5-10 хв), щоб бот працював 24/7 безкоштовно!
