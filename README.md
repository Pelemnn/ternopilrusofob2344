# 🇺🇦 Telegram-бот «Патріотична Музика MP4» (100 Пісень)

Спеціалізований Telegram-бот на Python (aiogram 3.x), який містить базу зі **100 культових українських пісень** та надсилає **ВИКЛЮЧНО РЕАЛЬНІ MP4 ВІДЕО-ТРЕКИ** (без посилань):

1. ⏰ **Автоматично кожні 10 хвилин** (або за вашим налаштованим інтервалом) у всі групи/чати, де додано бота!
2. 🎵 **За командою `/music`** (або `/song`) у будь-який момент.
3. ⚙️ **Налаштування інтервалу таймера `/settings [час]`** (наприклад: `/settings 5m`, `/settings 15m`, `/settings 1h`).
4. 🎬 **Зручне додавання нових MP4 відео** через команду `/addmusic` (адміном прямо в Telegram).
5. 🌐 **Працює 24/7 на Render.com** із вбудованим HTTP health-check сервером.

## 🚀 Команди бота

### Для всіх учасників:
- `/start` — Запустити бота та зареєструвати чат для авто-відправки.
- `/music` (або `/song`, `/play`) — Надіслати випадкову MP4 пісню зараз.
- `/list` — Переглянути каталог 100 пісень.
- `/help` — Довідка з командами.

### Налаштування та адміністрування:
- `<code>/settings</code>` — Переглянути поточний інтервал відправки пісень у чаті.
- `<code>/settings [час]</code>` — Змінити інтервал автоплею.
  - *Приклади:* `<code>/settings 5m</code>`, `<code>/settings 10m</code>`, `<code>/settings 15m</code>`, `<code>/settings 30m</code>`, `<code>/settings 1h</code>`, `<code>/settings 2h</code>`.
- `<code>/autoplay on</code>` або `<code>/autoplay off</code>` — Увімкнути/вимкнути автоплей у чаті.
- `<code>/addmusic [назва]</code>` (для адміна) — Надіслати нове MP4 відео в бот.

## 🌐 Розгортання на Render.com

1. Завантажте файли на GitHub:
   ```bash
   git init
   git add .
   git commit -m "100 MP4 Songs Music Bot"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГІН/ВАШ_РЕПОЗИТОРІЙ.git
   git push -f origin main
   ```
2. На [dashboard.render.com](https://dashboard.render.com/) створіть **Web Service** з репозиторію:
   - **Language / Runtime:** `Python 3`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
   - **Instance Type:** `Free`
3. У вкладці **Environment Variables** додайте:
   - `BOT_TOKEN` = `ваш_токен_від_BotFather`
4. Натисніть **Deploy Web Service**!
5. Налаштуйте пінг на [UptimeRobot](https://uptimerobot.com/) на `https://ваш-сервіс.onrender.com/health` (кожні 5-10 хв) для роботи 24/7!
