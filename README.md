# 🇺🇦 Telegram-бот «Анти-Русифікатор»

Потужний і розумний Telegram-бот на Python (aiogram 3.x), створений для очищення українських чатів від російської мови, московитських слів, матів та одруківок із прогресивною системою покарань (мут-драбина), заміною на колоритну українську лайку та патріотичним гумором.

---

## 🚀 Основний функціонал

1. **Розумна детекція мови та одруківок:**
   - **Унікальні літери:** Миттєве виявлення літер `ы`, `ё`, `ъ`, `э` (великих та малих).
   - **Словник та патерни:** Виявлення суто російських слів (*«полотенце»*, *«привет»*, *«спасибо»*, *«пожалуйста»*, *«почему»*, *«конечно»*, *«сейчас»*, *«вообще»*, *«нравится»* тощо).
   - **Ловля одруківок (Fuzzy Matching):** Якщо порушник робить одруківку на клавіатурі або спеціально спотворює російське слово (*«блч»* замість *«бля»*, *«првет»*, *«полотнце»*, *«пздц»*) — бот все одно розпізнає та видасть мут!
   - **Обхід фільтрів (Leetspeak):** Захист від приховування слів символами (*«бл@ть»*, *«$ука»*, *«п0шел»*).
   - **Захист від хибних спрацьовувань:** Українські слова (*«рушник»*, *«дякую»*, *«читаю»*, *«знаю»*, *«трясця»*, *«дідько»*, *«курва»*, *«срака»*) не блокуються.

2. **Заміна російських матів на соковиту українську лайку:**
   - Якщо виявлено російську лайку, бот підказує порушнику колоритний український аналог:
     - Замість *«блять» / «бля»* 💡 *«Трясця! / Хай йому грець! / Дідько!»*
     - Замість *«пошел нахуй»* 💡 *«Йди до сраки! / Під три чорти!»*
     - Замість *«сука»* 💡 *«Курва! / Стерво! / Падлюка!»*
     - Замість *«пиздец»* 💡 *«Срака! / Халепа! / Лихо!»*
     - Замість *«ебать»* 💡 *«Йосип драний! / А щоб тебе підняло та гепнуло!»*
     - Замість *«хуйня»* 💡 *«Дурня! / Хрінь! / Срамота!»*
     - Замість *«еблан» / «долбоеб»* 💡 *«Бовдур! / Йолоп! / Недотепа!»*

3. **Прогресивна драбина мутів (Mute Ladder):**
   - 1-ше порушення: **5 хвилин**
   - 2-ге порушення: **15 хвилин**
   - 3-тє порушення: **30 хвилин**
   - 4-те порушення: **1 година (60 хв)**
   - 5-те порушення: **12 годин**
   - 6-те порушення: **24 години (1 доба)**
   - 7-ме+ порушення: **36 годин (1.5 доби)**

4. **Патріотичні відповіді з приколами:**
   - Повідомлення супроводжуються випадковими українськими гаслами та жартами (*«Путін — Хуйло!»*, *«Бавовнятко плаче...»*, *«Щелепа заклинила?»*, *«Паляниця, полуниця, укрзалізниця»* тощо).

5. **База даних SQLite (aiosqlite):**
   - Автоматичне збереження кількості порушень кожного учасника за кожним чатом.

6. **Команди бота:**
   - `/start` — Привітання та інформація.
   - `/help` — Довідка з командами.
   - `/my_punishments` — Перевірити свій рахунок порушень.
   - `/top` — Топ порушників чату.
   - `/unmute` *(тільки адміни, відповіддю на повідомлення)* — Зняти мут.
   - `/reset` *(тільки адміни, відповіддю на повідомлення)* — Скинути лічильник покарань.

## 🌐 Як розгорнути бота на Render.com (Покрокова інструкція)

Бот повністю оптимізований для **Render.com** (має вбудований HTTP-сервер для проходження безкоштовних health check перевірок Render).

### Крок 1: Завантажте проєкт на GitHub
1. Створіть новий репозиторій на [GitHub](https://github.com/new) (наприклад, `anti-rus-bot`).
2. Запустіть команди у папці проєкту:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of anti-rus bot"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГІН/anti-rus-bot.git
   git push -u origin main
   ```

### Крок 2: Створіть сервіс на Render.com
1. Зареєструйтесь / увійдіть на [Render.com](https://dashboard.render.com/).
2. Натисніть кнопку **New +** -> виберіть **Web Service**.
3. Підключіть свій GitHub-репозиторій `anti-rus-bot`.
4. Заповніть поля налаштувань:
   - **Name:** `anti-rus-telegram-bot` (або будь-яка назва)
   - **Language:** `Python 3`
   - **Branch:** `main`
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
   - **Instance Type:** `Free`
5. Перейдіть до розділу **Environment Variables** (Змінні оточення) та додайте:
   - **Key:** `BOT_TOKEN`
   - **Value:** `ваш_токен_від_BotFather`
   - *(Опціонально)* **Key:** `PYTHON_VERSION`, **Value:** `3.11.8`
6. Натисніть **Deploy Web Service**.

### Крок 3: Налаштуйте Keep-Alive (щоб Free Tier не засинав)
На безкоштовному тарифі Render сервіси засинають, якщо на їхній HTTP-URL немає запитів протягом 15 хвилин.
1. Скопіюйте посилання на ваш сервіс на Render (наприклад: `https://anti-rus-telegram-bot.onrender.com`).
2. Зареєструйтесь на безкоштовному сервісі моніторингу типу [UptimeRobot](https://uptimerobot.com/) або [Cron-Job.org](https://cron-job.org/).
3. Створіть моніторинг (HTTP ping кожні 5-10 хвилин) на вашу адресу `https://anti-rus-telegram-bot.onrender.com/health`.
4. Бот буде працювати **24/7 абсолютно безкоштовно**!

## 💻 Локальний запуск

1. Створіть файл `.env`:
   ```env
   BOT_TOKEN=123456789:ABCdefGhIJKlmNoPQRsTUVwxyZ
   ```
2. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустіть:
   ```bash
   python bot.py
   ```
4. Запуск тестів:
   ```bash
   python test_detector.py
   ```

## 👥 Налаштування в Telegram-групі

1. Додайте бота в групу/супергрупу.
2. Призначте його **Адміністратором (Admin)** та увімкніть дозволи:
   - 🔒 **Обмеження учасників (Restrict / Ban members)**
   - 🗑️ **Видалення повідомлень (Delete messages)**
